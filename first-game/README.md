# 月影 TSUKIKAGE

和の月夜を舞台にした、HTML / CSS / JavaScript製の横スクロールシューティングMVPです。

## 遊び方

`index.html` をブラウザーで開くとプレイできます。移動は矢印キーまたは WASD、射撃はスペースキーです。スマートフォンでは画面下の方向ボタンと FIRE ボタンを使います。

敵は10種類の雑魚が順番に登場し、それぞれ異なる動きや弾幕で攻撃してきます。雑魚を10体倒すと大将「羅刹」が出現。敵弾や接触で3回被弾するとゲームオーバー、羅刹を倒すとクリアです。「再び出陣する」で最初から挑戦できます。

## ファイル構成

- `index.html`: ゲーム画面とHUD
- `style.css`: レイアウトとレスポンシブ対応
- `script.js`: 描画、操作、スコア、ゲーム進行
